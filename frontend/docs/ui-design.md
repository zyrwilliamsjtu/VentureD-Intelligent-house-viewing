# AI 代看房 · UI 设计说明（视觉规范 + 界面文案全览）

> 本文是前端界面的**唯一整理稿**：把设计语言、页面结构、全部界面文案、实景素材映射、关键交互一次性收拢。用于路演讲解、团队交接、以及给外部（如命名 / 评审）快速了解产品界面。事实源：`frontend/src/`（组件 + 样式）+ `frontend/public/assets/`。日期：2026-08-28。

## 1. 产品与页面总览

「AI 代看房 · VentureD」——第一人称 3DGS 点云实景漫游 + AI 置业顾问语音带看。桌面 Chrome / Edge 优先，适配 1280–1440。

页面流转共三层（`src/App.tsx`）：

```
开场落地页 Splash  →  房源列表 HouseList  →  第一人称漫游 WalkHud
```

| 页面 | 组件 | 定位 | 视觉风格 |
|---|---|---|---|
| 开场落地页 | `components/Splash.tsx` | 品牌门面 + 搜索 + 精选 + 顾问 + 预约 | 浅色奢华（对齐 LuxeEstate Demo） |
| 房源列表 | `components/HouseList.tsx` | 全部房源 + 筛选 + 户型图 | 白卡圆角，与落地页同套语言 |
| 漫游 HUD | `components/WalkHud.tsx` | 3D 漫游覆盖层 + AI 对话 | 白玻璃面板 + 极简 HUD |

性能红线：落地页**不挂 3D 引擎**（纯 DOM）；列表页挂载但暂停点云渲染；仅漫游页真正渲染（详见 `WORKLOG.md` 阶段 22）。

## 2. 设计语言（Design Tokens）

来源：`src/styles/global.css` 的 `:root`。

### 2.1 配色

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#ffffff` | 页面底色 |
| `--bg-2` | `#f8fafc` | 浅灰交替分节背景 |
| `--ink` | `#101828` | 主文字（近黑蓝灰） |
| `--ink-2` | `#5b6472` | 次级文字 |
| `--ink-3` | `#9aa3b2` | 弱化文字 / 说明 |
| `--brand` | `#0077b6` | 主按钮、链接、强调蓝 |
| `--brand-deep` | `#075e91` | 主色加深 |
| `--gold` | `#ffd700` | 金色点缀（徽标、页脚小标题） |
| `--gold-deep` | `#e6b800` | 金色加深 |
| `--ai` | `#5e7e99` | AI 语义蓝灰 |
| `--ok` | `#3e9b6e` | 成功 / 在线点 |
| `--warn` | `#c77d2e` | 警告 |
| `--canvas-bg` | `#eef1f5` | 3D 画布底色 |

页脚深色：`#1e293b`（深蓝灰），文字白色系。

### 2.2 字体

| Token | 字体栈 | 用途 |
|---|---|---|
| `--font-display` | `Cinzel, 'Noto Serif SC', 'Playfair Display', 'Songti SC', serif` | 大标题 / 房源名 / 数字 |
| `--font-mono` | `Space Mono, monospace` | 小标签 / 元信息 / 英文 kicker |
| `--font` | `'DM Sans', 'Noto Sans SC', PingFang SC, 'Microsoft YaHei', sans-serif` | 正文 |

中文字自动回落 Noto Serif SC（标题）/ 系统无衬线（正文）；英文字（kicker、数字）用 Cinzel / DM Sans。

### 2.3 圆角 / 阴影 / 层次

- 卡片圆角：`16px`（大卡）/ `10px`（输入、图标）/ `8px`（按钮）。
- 卡片投影：`0 4px 20px rgba(15,23,42,.06)`，悬停上浮 `translateY(-6px)` + 加深投影。
- 玻璃拟态：`backdrop-filter: blur(14px) saturate(150%)`，白底 90% 透明度，仅用于导航 / 搜索卡 / 面板等小面积。
- 层级：`hud-tr 23 > agent-panel 22 > resume-overlay 21 > walk-hud 20`；`boot-status 25`、`no-webgl 30`。

## 5. 漫游 HUD（WalkHud）

### 5.1 左上（房源信息）

- `‹ 返回`（回列表）
- 房源胶囊：`{房源名} {面积}㎡ · {价格}`
- 徽标：`LOD 流式 · 体素碰撞 · 点击传送`

### 5.2 右上（房间 + AI 入口）

- 房间胶囊：`{当前房间}`（未识别时 `自由漫游`）
- AI 按钮：`AI 讲解 · 询问`（带呼吸绿点）

### 5.3 AI 对话面板

- 标题 `AI 置业顾问` + `一键带看` + `收起`
- 引导语：`试试：「介绍一下这套房」「主卧在哪」「多少钱」` + `也可以按住 🎙 说话`
- 输入框占位：`输入问题，回车发送` / 录音时 `正在录音…松开发送`
- 麦克风按钮（按住说话，松开发送，≤15s）；`发送` 按钮
- 等待态：`思考中…` / `语音识别中…`
- 回复气泡带 `🔊` 朗读按钮
- 快捷键 `T` 呼出/收起面板

### 5.4 其他 HUD 元素

- 中央 toast：主文案 + 副文案，2.6s 自动消失
- 准星 `crosshair`：指针锁定时显示，点击视线落点传送
- 底部提示条：`W A S D 移动 · 鼠标 视角 · 点击 传送 · Shift 快走 · T AI 讲解 · ESC 释放鼠标`
- 恢复层（未锁定时）：`点击继续漫游` / `WASD 移动 · 鼠标控制视角 · ESC 暂停`
- 录音态视觉反馈：麦克风 `recording`（脉冲）/ `recognizing`（变色）

### 5.5 语音 / 反馈文案

| 场景 | 文案 |
|---|---|
| 麦克风权限拒绝 | `麦克风不可用 / 请允许麦克风权限，或用打字输入` |
| 空语音 | `没听清 / 请再按住说一次` |
| 语音识别失败 | `语音识别失败 / {原因}` |
| 未选房点带看 | `请先选择房源 / 再开始全屋带看` |
| Agent 不可达 | `Agent 暂不可用：{原因}` |
| 传送成功 | `已传送 · {房间}` |
| 传送不可用 | `传送点不可用 / {原因}` |
| 落点被挡 | `落点被挡住了 / 换个角度看目标位置` |

## 7. 关键交互行为

- 开场 → `开始看房` / 搜索卡 `搜索房源`（带筛选）→ 列表页
- 列表卡点击 → 选房（换房重置会话）→ 指针锁定 + 进漫游
- 漫游：WASD 移动、鼠标视角、Shift 快走、点击传送、T 呼 AI、ESC 释放
- 语音：按住 🎙 录音 → 松开 → ASR 转文字 → 自动发送
- 进房：`room_id` 切换防抖触发 `enter_room` → toast + TTS（每房间每会话一次）
- Agent 动作：`teleport` 瞬移 / `show_card` toast 信息卡 / `highlight` 占位 toast
- 搜索筛选写入 store（`filters: layout/price`），列表页过滤 + 顶部 chip + 一键清除
