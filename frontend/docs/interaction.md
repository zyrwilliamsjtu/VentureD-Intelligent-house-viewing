# 交互说明文档（Interaction Specification）

> 每个界面层级的全部可交互元素：是什么控件、怎么触发、触发后发生什么、状态如何变化。
> 与 `ui-design.md`（长什么样 / 文案）+ `../docs/architecture.md`（架构）配套使用。日期：2026-08-28。

约定标记：`触发 → 动作 → 状态变化`。

---

## 1. 开场落地页（Splash）

### 1.1 顶部导航

| 元素 | 交互 |
|---|---|
| 菜单「实景预览 / 精选房源 / 核心优势 / 顾问团队 / 预约看房」 | 点击 → `scrollTo(id)` 平滑滚动到对应区块 |
| 主按钮「开始看房」 | 点击 → `enterList()` → 进入列表页（view='list'） |

### 1.2 Hero 搜索卡

| 元素 | 交互 |
|---|---|
| 下拉「位置」 | 选择 → 目前仅「上海」一项 |
| 下拉「户型」 | 选择 → `setLayout`（全部户型 / 三室一厅 / 四室一厅） |
| 下拉「价格」 | 选择 → `setPrice`（全部 / 300万以下 / 300-450万 / 450万以上） |
| 按钮「搜索房源」（表单提交） | 提交 → `setFilters({layout,price})` + `enterList()` → 列表页按筛选过滤 |

### 1.3 精选房源

| 元素 | 交互 |
|---|---|
| 房源卡（整卡可点） | 点击 → `selectListing(l)`（换房重置会话）+ 请求指针锁定 → 直接进入 3D 漫游 + toast 欢迎 |
| 「查看全部 5 套 →」 | 点击 → `enterList()` → 列表页 |

### 1.4 预约表单

| 元素 | 交互 |
|---|---|
| 输入「姓名 / 手机号 / 留言」、下拉「意向房源」 | 常规输入（姓名、手机号必填） |
| 按钮「提交预约」（表单提交） | 提交 → `preventDefault` + `showToast('预约已提交', …)` |

### 1.5 页脚

| 元素 | 交互 |
|---|---|
| 三列链接「房源 / 服务 / 关于」 | 点击 → `scrollTo('tour')`（当前统一滚回顶部，占位待完善） |

## 2. 房源列表页（HouseList）

| 元素 | 交互 |
|---|---|
| 房源卡（整卡可点） | 点击 → `selectListing(l)` + 请求指针锁定 → 进漫游；toast：可漫游「欢迎来到 …」/ 未就绪「点云 LOD 转码中 …」 |
| 筛选条「清除 ✕」 | 点击 → `clearFilters()` → 恢复全部房源 + 移除筛选 chip |
| 空态「清除筛选」 | 点击 → `clearFilters()` |

## 3. 漫游 HUD（WalkHud）

### 3.1 左上

| 元素 | 交互 |
|---|---|
| 「‹ 返回」 | 点击 → `backToList()` → 释放指针锁定 + 回列表（3D 视口不卸载） |
| 房源胶囊 | 纯展示（房源名 + 面积 + 价格） |
| 徽标「LOD 流式 · 体素碰撞 · 点击传送」 | 纯展示 |

### 3.2 右上 / AI 对话面板

| 元素 | 交互 |
|---|---|
| 「AI 讲解 · 询问」 | 点击 → 打开面板（同时退出指针锁定、聚焦输入框） |
| 「一键带看」 | 点击 → `runTour()`：按 tour 步骤逐房间传送 + 讲解 + 朗读；未选房则 toast「请先选择房源」 |
| 「收起」 | 点击 → 关闭面板 |
| 回复气泡「🔊」 | 点击 → 朗读该条回复（`speakText`） |
| 输入框 | 输入 → 更新内容；回车 → 发送；等待 / 录音中禁用 |
| 「发送」 | 点击 → `send()`（发送当前输入，空内容禁用） |

### 3.3 语音按钮（Push-to-Talk）

| 交互 | 说明 |
|---|---|
| 按下（pointerdown） | `startVoice()`：请求麦克风 → 进入「录音中」脉冲态（≤15s 自动停止） |
| 松开（pointerup） | `finishVoice()`：停录 → 若 <300ms 丢弃 → 否则「识别中」→ ASR 转文字 → 自动发送 |
| 移出（pointerleave） | 录音中则触发 `finishVoice()` |
| 权限拒绝 | toast「麦克风不可用 / 请允许麦克风权限，或用打字输入」 |
| 空语音 | toast「没听清 / 请再按住说一次」 |

### 3.4 3D 画布 / 键鼠（AholoViewport + HUD）

| 交互 | 说明 |
|---|---|
| W A S D / 方向键 | 移动 |
| 鼠标（指针锁定时） | 视角 |
| Shift | 快走 |
| 点击（指针锁定时） | 视线落点传送（无体素时沿视线冲刺 2.2m） |
| T | 呼出 / 收起 AI 面板（输入框聚焦时不抢键） |
| ESC | 释放鼠标（浏览器指针锁定行为） |
| V | 视角校准（z-up 世界循环出生候选 A–E，联调用） |
| 恢复层「点击继续漫游」 | 点击 → 重新锁定指针 |

### 3.5 提示（toast）

| 触发 | 文案 |
|---|---|
| 选房进漫游 | `欢迎来到 {房源}` / `{房源}` |
| 传送成功 | `已传送 · {房间}` |
| 传送点不可用 | `传送点不可用 / …` |
| 落点被挡 | `落点被挡住了 / 换个角度看目标位置` |
| Agent 不可达 | `Agent 暂不可用：{原因}` |

## 4. 状态来源一览

| 状态 | 写入方 | 读取方 |
|---|---|---|
| `view`（splash/list/walk） | Splash/List/HUD 的按钮 | App 决定挂哪层 |
| `listing` | `selectListing` | HUD 房源胶囊、chat 请求 |
| `filters`（layout/price） | 搜索卡 `setFilters`、清除按钮 | HouseList 过滤 |
| `player`（眼位/朝向/房间） | AholoViewport 节流发布 | chat 请求上下文 |
| `teleportCmd` | agent 动作执行 | AholoViewport 订阅执行 |
| `toast` | 各处 `showToast` | CenterToast 显示 |
