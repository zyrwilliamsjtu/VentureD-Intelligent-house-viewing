## 6. 问题清单

### 🔴 阻断（已修、已重测）

| 项 | 影响 | 修复 | 耗时 |
|----|------|------|------|

### 🟡 建议（不阻塞 demo）

| 项 | 说明 |
|----|------|
| 自由答 12–31s | 方舟延迟；demo 话术预留等待，或只对非问价走 LLM |
| chat 成功也会打 TTS | 问价/导航被拉到 ~1.7s；前端若只用气泡可忽略 `tts_url` |
| 0309/0836 房间推断 | 0330 规则把开间标成厨房（无独立客厅）——文案别说「大客厅」除非 listing.highlight |
| listings 500 | 后端不内置硬编码列表（契约如此）；A 必须做本地兜底 |

### 🔵 优化

| 项 | 说明 |
|----|------|
